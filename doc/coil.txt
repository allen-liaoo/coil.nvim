1. INTRODUCTION                                          *coil* *coil-intro*

coil adds a column view with file previews to oil.nvim
(https://github.com/stevearc/oil.nvim). The view opens in its own tab, with
three panes: the parent directory, the current directory (an oil buffer), and
a preview of the entry under the cursor.

==============================================================================
2. SETUP                                                        *coil-setup*

Set up oil.nvim as usual, then coil. `require("coil").setup()` is optional;
call it to change the defaults (|coil-options|).

Optional tools:
- Images in the preview: image.nvim (https://github.com/3rd/image.nvim),
  which requires ImageMagick. Video thumbnails need ffmpeg, and PDFs need
  poppler's `pdftoppm`.
- Previews of remote files: `scp` for SSH and the `aws` CLI for S3 (same
  requirements as oil).
- Git status in every pane: oil-git-status.nvim
  (https://github.com/refractalize/oil-git-status.nvim).

`:checkhealth coil` reports what is installed.

==============================================================================
3. COMMANDS                                                  *coil-commands*

                                                                       *:Coil*
:Coil [dir...]          Open the column view on each directory, one tab each
                        (default: the current buffer's directory).

                                                                  *:CoilClose*
:CoilClose              Close the column view.

                                                                *:CoilPreview*
:CoilPreview            In a plain oil window, toggle a preview split that
                        follows the cursor.

                                                             *:CoilClearCache*
:CoilClearCache         Delete the cached image thumbnails.

                                                             *:CoilInstallCli*
:CoilInstallCli [dir]   Link the `coil` command (|coil-standalone|) into
                        `~/.local/bin` (or `dir`).

Commands typed in the middle pane that open something, such as `:Oil`,
`:edit file`, `:buffer` or `:vsplit`, run in your editing tab instead, so
plain oil is always one command away, even for the directory the middle pane
shows. `:Coil dir` moves the column view, `:edit` on its own reloads the
middle pane, and other commands (`:w`, `:s`, ...) run there as usual.

==============================================================================
4. KEYS                                          *coil-keys* *coil-keymaps*

The middle pane is an oil buffer, and oil's keys work there as usual, except
some behaviors are changed (e.g. `<C-h>` opens a horizontal split in the
editor tab, not the tab showing coil).

coil adds its own keys, set with the `keymaps` option the way oil's
`keymaps` is set. Their defaults differ in standalone mode
(|coil-standalone|); "none" means no key until you map one.

                                                               *coil-actions*
Action          Plugin          Standalone      Does ~
actions.go_in   L, <Right>      L, <Right>      Enter a directory
actions.go_out  H, <Left>       H, <Left>       Go to the parent directory
actions.down    j, <Down>       j, <Down>       Move down, from the last entry
                                                to the first
actions.up      k, <Up>         k, <Up>         Move up, from the first entry
                                                to the last
actions.close   q               none            Close coil's tab (the column
                                                view)
actions.quit    none            q               Quit Neovim, asking about
                                                unsaved changes
actions.cancel  none            Q               Quit like quit, but write
                                                nothing to --cwd-file or
                                                --chooser-file

`down` and `up` work in visual mode too. The close, quit and cancel keys also
work in the preview pane.

A key maps to an action, a function, keys to type (such as
`"<Cmd>...<CR>"`), or a table with one of those (first item or `callback`)
and `mode`, `desc` or `opts` (passed to a function); `false` removes a
default. Keys are for normal mode unless `mode` says otherwise (`"n"`, `"x"`,
`"v"` or `""`, or a list). >lua
    require("coil").setup({
      keymaps = {
        ["l"] = "actions.go_in",
        ["gz"] = { callback = function() print("hi") end, desc = "Say hi" },
        ["q"] = false,
      },
    })

5. OPTIONS                                                    *coil-options*

The defaults: >lua
    require("coil").setup({
      -- Relative widths of the parent, current and preview panes
      ratio = { 1, 4, 3 },
      -- Wait this long (ms) after the cursor stops before updating the
      -- preview
      debounce_ms = 30,
      -- Name the column view's tab after the current directory. Sets the
      -- tab variable `tabname`, which tab lines such as lualine's `tabs`
      -- component show.
      tab_title = true,
      -- Open files that aren't text (images, videos, audio, PDFs, archives,
      -- other binary files) in the system's default program instead of the
      -- editor. Local files only; the split and tab keys still open them in
      -- the editor.
      open_external = false,
      -- Open text files in this Neovim. When false, they open in the
      -- system's text editor: XDG's default for text/plain, otherwise
      -- $VISUAL or $EDITOR, otherwise here. Editors that need a terminal
      -- open in a new terminal window (xdg-terminal-exec or $TERMINAL).
      -- Local files only; the split and tab keys still open them here.
      edit_here = true,
      -- Show each pane's path in a title line (winbar) above it
      winbar = false,
      -- coil's keys in the middle pane, set like oil's `keymaps` (see
      -- coil-keys)
      keymaps = {
        ["L"] = "actions.go_in",
        ["<Right>"] = "actions.go_in",
        ["H"] = "actions.go_out",
        ["<Left>"] = "actions.go_out",
        ["j"] = "actions.down",
        ["<Down>"] = "actions.down",
        ["k"] = "actions.up",
        ["<Up>"] = "actions.up",
        ["q"] = "actions.close",
      },
      preview = {
        -- Text files larger than this get no text preview
        max_bytes = 2 * 1024 * 1024,
        -- Read at most this many lines of a text file
        max_lines = 1000,
        -- Bytes read to tell binary from text
        sniff_bytes = 8192,
        -- Wait this long (ms) before showing "Loading..." for a slow
        -- directory
        loading_delay_ms = 100,
        -- Draw images (and video frames, PDF pages) with image.nvim when it
        -- is installed and set up
        images = true,
        -- Wait this long (ms) after the cursor stops on an image before
        -- working on it
        image_delay_ms = 100,
        -- Images are drawn from thumbnails that fit {width, height} pixels
        -- (only read by setup())
        thumbnail_size = { 600, 900 },
        -- In the column view, also make thumbnails for images this many
        -- entries from the cursor
        prefetch = 2,
        -- Size limit of the thumbnail cache, in MiB; the least recently
        -- used go first (false: none)
        thumbnail_cache_mb = 200,
        -- Remote files (SSH, S3) are downloaded for a preview. Wait this
        -- long (ms) after the cursor stops on one before downloading it
        remote_delay_ms = 200,
        -- Remote images, videos and PDFs larger than this aren't downloaded
        -- (other files: max_bytes)
        remote_max_bytes = 20 * 1024 * 1024,
        -- Size limit of the downloaded copies, in MiB (false: none). They
        -- are deleted when Neovim exits.
        remote_cache_mb = 100,
      },
      -- Options for when Neovim is started as a file manager (see
      -- coil-standalone). Takes any option except itself. These defaults
      -- give way to the options you set; your own `standalone` options win
      -- over everything.
      standalone = {
        open_external = true,
        edit_here = false,
        keymaps = { ["q"] = "actions.quit", ["Q"] = "actions.cancel" },
      },
    })
<

6. STANDALONE MODE                                         *coil-standalone*

coil can also run as a terminal file manager: the `coil` command
(|:CoilInstallCli|) starts Neovim in standalone mode, which sets
`g:coil_standalone` (`nvim --cmd "let g:coil_standalone = 1"` does the same).
In this mode the `standalone` options (|coil-options|) apply over the
others: by default, files open in the system's default programs, and `q`
quits Neovim.
|coil.standalone()| tells your config which mode it runs in.

coil's README (https://github.com/allen-liaoo/coil.nvim) covers the command's
arguments, changing the shell's directory on exit, the Nix `coil` binary, and
using coil as the system's file chooser.

7. LUA API                                                        *coil-api*

                                                               *coil.setup()*
coil.setup({opts})      Set coil's options (|coil-options|). Optional.

                                                                *coil.open()*
coil.open({dirs})       Like |:Coil|: open the column view on each directory,
                        one tab each. {dirs} is a path or oil URL, a list of
                        them, or nil for the current buffer's directory.

                                                               *coil.close()*
coil.close()            Like |:CoilClose|: close the current tab's column
                        view (otherwise the one used most recently).

                                                          *coil.standalone()*
coil.standalone()       Whether Neovim was started as a file manager
                        (|coil-standalone|). Known from the start, so your
                        config can check it while it loads: >lua
                            require("oil").setup({
                              delete_to_trash = require("coil").standalone(),
                            })
<

8. HIGHLIGHTS                                              *coil-highlights*

coil links these groups by default; set them to change coil's colours.

CoilParentSelected      The current directory in the parent pane. Links to
                        |hl-Visual|.
CoilDir                 Directories in |:CoilPreview|'s directory listings.
                        Links to `OilDir` (else |hl-Directory|).
CoilLink                Links there. Links to `OilLink` (else `Constant`).
CoilDirHidden           Hidden directories there. Links to `OilDirHidden`
                        (else `Comment`).
CoilFileHidden          Hidden files there. Links to `OilFileHidden` (else
                        `Comment`).
CoilLinkHidden          Hidden links there. Links to `OilLinkHidden` (else
                        `Comment`).
