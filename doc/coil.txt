1. INTRODUCTION                                          *coil* *coil-intro*

coil adds a column view with file previews to oil.nvim
(https://github.com/stevearc/oil.nvim), in your Neovim or as a terminal file
manager. The view opens in its own tab, with three panes: the parent
directory, the current directory (an oil buffer), and a preview of the entry
under the cursor.

Try it with Nix (flakes enabled): >sh
    nix run github:allen-liaoo/coil.nvim               # the current directory
    nix run github:allen-liaoo/coil.nvim -- ~/some/dir  # a given directory
<
==============================================================================
2. REQUIREMENTS                                            *coil-requirements*

- Neovim 0.10 or newer (developed and tested on 0.12)
- oil.nvim. coil uses some of oil's internals.
- For images in the preview (optional): image.nvim
  (https://github.com/3rd/image.nvim), which requires ImageMagick. Video
  thumbnails need ffmpeg, and PDFs need poppler's `pdftoppm`.
- For previews of remote files: `scp` for SSH and the `aws` CLI for S3 (same
  requirements as oil).
- For git status (optional): oil-git-status.nvim
  (https://github.com/refractalize/oil-git-status.nvim).

`:checkhealth coil` reports what is installed.

                                                             *coil-tmux*
In tmux, image.nvim needs this setup: >lua
    require("image").setup({
      -- The default, cursor-based kitty method puts images at the cursor
      -- in tmux
      kitty_method = "unicode-placeholders",
      -- Show images only in the active tmux window
      tmux_show_only_in_active_window = true,
    })
<
and tmux needs this config: >tmux
    set -gq allow-passthrough on
    set -g visual-activity off
    set -g focus-events on
<
==============================================================================
3. SETUP                                                        *coil-setup*

Set up oil.nvim as usual, then coil. `require("coil").setup()` is optional;
call it to change the defaults (|coil-options|).

lazy.nvim: >lua
    {
      "allen-liaoo/coil.nvim",
      dependencies = {
        "stevearc/oil.nvim",
        -- Optional, for images. `opts = {}` runs its setup()
        { "3rd/image.nvim", opts = {} },
      },
      opts = {}, -- see coil-options
    }
<
vim.pack (Neovim 0.12+): >lua
    vim.pack.add({
      "https://github.com/stevearc/oil.nvim",
      "https://github.com/allen-liaoo/coil.nvim",
    })
    require("oil").setup()
    -- require("image").setup()
    require("coil").setup()
<
Nix: the flake has the plugin as `packages.<system>.coil-nvim`
(`nix/coil-nvim.nix` without flakes). You still need to install its
dependencies (oil.nvim, image.nvim) separately. For nixvim, the flake has a
module, `nixvimModules.default`, adding options under `plugins.coil`.

==============================================================================
4. COMMANDS                                                  *coil-commands*

                                                                       *:Coil*
:Coil [dir...]          Open the column view on each directory, one tab each
                        (default: the current buffer's directory).

                                                                  *:CoilClose*
:CoilClose              Close the column view.

                                                                *:CoilPreview*
:CoilPreview            In a plain oil window, toggle a preview split that
                        follows the cursor.

                                                             *:CoilClearCache*
:CoilClearCache         Delete the cached image thumbnails.

                                                             *:CoilInstallCli*
:CoilInstallCli [dir]   Link the `coil` command (|coil-cli|) into
                        `~/.local/bin` (or `dir`).

Commands typed in the middle pane that open something, such as `:Oil`,
`:edit file`, `:buffer` or `:vsplit`, run in your editing tab instead, so
plain oil is always one command away, even for the directory the middle pane
shows. `:Coil dir` moves the column view, `:edit` on its own reloads the
middle pane, and other commands (`:w`, `:s`, ...) run there as usual.

5. KEYS                                          *coil-keys* *coil-keymaps*

The middle pane is an oil buffer, and oil's keys work there as usual, except
some behaviors are changed (e.g. `<C-h>` opens a horizontal split in the
editor tab, not the tab showing coil).

coil adds its own keys, set with the `keymaps` option the way oil's
`keymaps` is set. Their defaults differ in standalone mode
(|coil-standalone|); "none" means no key until you map one.

                                                               *coil-actions*
Action          Plugin          Standalone      Does ~
actions.go_in   L, <Right>      L, <Right>      Enter a directory
actions.go_out  H, <Left>       H, <Left>       Go to the parent directory
actions.down    j, <Down>       j, <Down>       Move down, from the last entry
                                                to the first
actions.up      k, <Up>         k, <Up>         Move up, from the first entry
                                                to the last
actions.close   q               none            Close coil's tab (the column
                                                view)
actions.quit    none            q               Quit Neovim, asking about
                                                unsaved changes
actions.cancel  none            Q               Quit like quit, but write
                                                nothing to --cwd-file or
                                                --chooser-file

`down` and `up` work in visual mode too. The close, quit and cancel keys also
work in the preview pane.

A key maps to an action, a function, keys to type (such as
`"<Cmd>...<CR>"`), or a table with one of those (first item or `callback`)
and `mode`, `desc` or `opts` (passed to a function); `false` removes a
default. Keys are for normal mode unless `mode` says otherwise (`"n"`, `"x"`,
`"v"` or `""`, or a list). >lua
    require("coil").setup({
      keymaps = {
        ["l"] = "actions.go_in",
        ["gz"] = { callback = function() print("hi") end, desc = "Say hi" },
        ["q"] = false,
      },
    })
<

6. OPTIONS                                                    *coil-options*

The defaults: >lua
    require("coil").setup({
      -- Relative widths of the parent, current and preview panes
      ratio = { 1, 4, 3 },
      -- Wait this long (ms) after the cursor stops before updating the
      -- preview
      debounce_ms = 30,
      -- Name the column view's tab after the current directory. Sets the
      -- tab variable `tabname`, which tab lines such as lualine's `tabs`
      -- component show.
      tab_title = true,
      -- Open files that aren't text (images, videos, audio, PDFs, archives,
      -- other binary files) in the system's default program instead of the
      -- editor. Local files only; the split and tab keys still open them in
      -- the editor.
      open_external = false,
      -- Open text files in this Neovim. When false, they open in the
      -- system's text editor: XDG's default for text/plain, otherwise
      -- $VISUAL or $EDITOR, otherwise here. Editors that need a terminal
      -- open in a new terminal window (xdg-terminal-exec or $TERMINAL).
      -- Local files only; the split and tab keys still open them here.
      edit_here = true,
      -- Show each pane's path in a title line (winbar) above it
      winbar = false,
      -- coil's keys in the middle pane, set like oil's `keymaps` (see
      -- coil-keys)
      keymaps = {
        ["L"] = "actions.go_in",
        ["<Right>"] = "actions.go_in",
        ["H"] = "actions.go_out",
        ["<Left>"] = "actions.go_out",
        ["j"] = "actions.down",
        ["<Down>"] = "actions.down",
        ["k"] = "actions.up",
        ["<Up>"] = "actions.up",
        ["q"] = "actions.close",
      },
      preview = {
        -- Text files larger than this get no text preview
        max_bytes = 2 * 1024 * 1024,
        -- Read at most this many lines of a text file
        max_lines = 1000,
        -- Bytes read to tell binary from text
        sniff_bytes = 8192,
        -- Wait this long (ms) before showing "Loading..." for a slow
        -- directory
        loading_delay_ms = 100,
        -- Draw images (and video frames, PDF pages) with image.nvim when it
        -- is installed and set up
        images = true,
        -- Wait this long (ms) after the cursor stops on an image before
        -- working on it
        image_delay_ms = 100,
        -- Images are drawn from thumbnails that fit {width, height} pixels
        -- (only read by setup())
        thumbnail_size = { 600, 900 },
        -- In the column view, also make thumbnails for images this many
        -- entries from the cursor
        prefetch = 2,
        -- Size limit of the thumbnail cache, in MiB; the least recently
        -- used go first (false: none)
        thumbnail_cache_mb = 200,
        -- Remote files (SSH, S3) are downloaded for a preview. Wait this
        -- long (ms) after the cursor stops on one before downloading it
        remote_delay_ms = 200,
        -- Remote images, videos and PDFs larger than this aren't downloaded
        -- (other files: max_bytes)
        remote_max_bytes = 20 * 1024 * 1024,
        -- Size limit of the downloaded copies, in MiB (false: none). They
        -- are deleted when Neovim exits.
        remote_cache_mb = 100,
      },
      -- Options for when Neovim is started as a file manager (see
      -- coil-standalone). Takes any option except itself. These defaults
      -- give way to the options you set; your own `standalone` options win
      -- over everything.
      standalone = {
        open_external = true,
        edit_here = false,
        keymaps = { ["q"] = "actions.quit", ["Q"] = "actions.cancel" },
      },
    })

7. STANDALONE FILE MANAGER                                 *coil-standalone*

You can use your Neovim with coil.nvim as a standalone file manager, or the
`coil` binary from coil's Nix flake. Standalone coil differs from coil as a
plugin: everything opens in the system's default programs, `q` quits Neovim,
and with shell integration (`docs/shell-integration.md` in coil's repository)
the shell changes to the last directory on exit.

                                                                   *coil-cli*
Usage: >
    coil [options] [directory...]
<
Opens the directories (the current one by default) in coil's column view.

  --cwd-file <path>      On exit, write the last directory to <path>
  --chooser-file <path>  Choose files instead of opening them: write their
                         paths to <path>, one per line, and quit. A visual
                         selection chooses all its entries.
  -h, --help             Show this help and exit
  -v, --version          Show coil's version and exit

Other arguments go to Neovim. After `--`, all arguments are file names.

BRING YOUR OWN NEOVIM                                          *coil-byo-nvim*

The plugin comes with a `coil` command in `bin/coil`. Run |:CoilInstallCli|
to put it on your `PATH`: it links `~/.local/bin/coil` (or `<dir>/coil` for
`:CoilInstallCli <dir>`) to the plugin's copy, so updating the plugin updates
the command too. A link of your own works the same: >sh
    # With lazy.nvim's default install directory
    ln -s ~/.local/share/nvim/lazy/coil.nvim/bin/coil ~/.local/bin/coil
<
It starts your Neovim (`nvim`, or `$COIL_NVIM`), with your config, in coil's
standalone mode, which turns on coil's `standalone` options.

                                                           *coil.standalone()*
Your config can check the mode with `require("coil").standalone()`, even
while it loads, to turn on behavior only in standalone mode: >lua
    require("oil").setup({
      delete_to_trash = require("coil").standalone(),
      watch_for_changes = true,
    })
<
- Don't lazy-load coil: with lazy.nvim, set
  `lazy = not vim.g.coil_standalone`.
- For a separate config, history and state, run it as another Neovim app:
  `COIL_APPNAME=coil` makes it read `~/.config/coil/init.lua` (which then has
  to install and set up oil.nvim and coil itself).

NIX BINARY                                                   *coil-nix-binary*

The flake's default package is a `coil` binary: Neovim with coil, plus all
its plugin and binary dependencies needed for file previews. >sh
    nix profile install github:allen-liaoo/coil.nvim
<
It runs as its own Neovim app (`NVIM_APPNAME=coil`), so its config is
`~/.config/coil/init.lua`, an ordinary Neovim config. After that runs, `coil`
sets up any bundled plugin it didn't: >lua
    -- ~/.config/coil/init.lua
    require("oil").setup({ view_options = { show_hidden = true } })
    require("coil").setup({ ratio = { 1, 3, 4 } }) -- see coil-options
    vim.cmd.colorscheme("retrobox")
<
SYSTEM FILE CHOOSER                                       *coil-file-chooser*

On Linux, xdg-desktop-portal-termfilechooser
(https://github.com/hunkyburrito/xdg-desktop-portal-termfilechooser) makes
apps' open and save dialogs run a terminal file manager. coil comes with a
wrapper for it, `bin/coil-termfilechooser` (both in the plugin and in the Nix
`coil`). Set it as the portal's `cmd` in
`~/.config/xdg-desktop-portal-termfilechooser/config`: >ini
    [filechooser]
    cmd=/path/to/coil.nvim/bin/coil-termfilechooser
    default_dir=$HOME
    open_mode=suggested
    save_mode=suggested
    ; Set TERMCMD to set the terminal to run coil in, with any options it
    ; takes. Otherwise it falls back to xdg-terminal-exec, else $TERMINAL -e.
    ; env=TERMCMD='<terminal> <options>'
    ; Any of coil's own settings, such as the Neovim to run
    ; env=COIL_NVIM=nvim
<
To choose a file, open it. To choose a directory, open it during a visual
selection, or quit inside it. `Q` (or `:cq`) cancels without choosing
anything.
